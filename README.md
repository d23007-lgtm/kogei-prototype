# こだわりから工芸を知る｜プロトタイプ

## 起動方法
1. `index.html` をブラウザで開いてください。
2. インターネット接続がある場合は Google Fonts の Inter が読み込まれます。オフラインでもシステムフォントで動作します。
3. 保存機能はブラウザの `localStorage` を使用します。同じブラウザ・同じ端末内で保存内容が残ります。

## ファイル構成
- `index.html` : 画面の構造
- `styles.css` : 配色・レイアウト・レスポンシブ表示
- `app.js` : 画面遷移、器のSVG描画、選択肢、タイマー、ライブラリ保存
- `assets/materials/` : 後から素材写真・テクスチャを配置するフォルダ
- `assets/works/` : 後から作品画像を配置するフォルダ

## 仕様メモ
- 配色：`#2B0800` / `#B03601` / `#CF4E35` / `#AA432E` / `#E9E9E7`
- 90秒タイマー、残り30秒以下で制作画面を赤みのある色に変更
- 器のプレビューはSVGで生成し、高さ・幅・輪郭の操作に連動
- 作品参考：国立美術館・豊田市美術館等の公開作品情報へリンク
- 作品からの「見方」はプロトタイプ上の解釈であり、作家本人の意図として断定しない

## これから差し替えるもの
素材の写真・テクスチャ、作品画像、タイトルロゴ・アイコン。作品画像を埋め込む場合は各所蔵館の利用条件を確認してください。

## v2 ブラッシュアップ
- 理想選択後に「スタート！」の準備画面を挟み、開始ボタンを押してから90秒タイマーを開始
- 制作終了時に完成画面・完成した器のプレビュー・紙吹雪アニメーションを表示
- 振り返り画面に制作サムネイルと5段階の自己評価を追加
- ライブラリに制作時のSVGサムネイル、自己評価、選んだ工夫、メモを保存
- 工芸作品の参考カードを理想ごとに5件ずつ表示。説明のあとに作品名・作家・所蔵情報を配置
- 全画面の行間、カード内の余白、見出しの優先順位を調整

## 素材テクスチャの追加方法
`assets/materials/README.txt` を参照してください。素材IDに合わせたファイル名で jpg / jpeg / png / webp を置くと、器のプレビューにテクスチャを重ねます。未配置の素材は色によるプレビューにフォールバックします。
